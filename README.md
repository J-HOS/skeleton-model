# Skeleton Model

Interactive 3D anatomical reference: select any structure to see the origin,
insertion, action and innervation of every muscle.

This repository holds the **built, deployable site** only (static files served
by GitHub Pages). It is generated by `02 Development/(C) build_deploy.py` in
the project folder - do not edit files here by hand; change the project and
rebuild.
